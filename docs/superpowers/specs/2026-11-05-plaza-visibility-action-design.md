# 策略广场展示操作

把公开展示作为策略详情的底部操作，避免在「策略信息」里另找开关。适用于 DCA 和 F&G。

- DCA 复用固定底栏；F&G 将暂停／恢复和删除从页头移到底栏，保留删除的既有行为。两者并列显示独立的「展示」或「取消展示」按钮，保留安全区及滚动留白。
- 未展示时，点击「展示」打开确认弹窗，复用 `presets.visibilityTitle` 和 `presets.visibilityHint`。取消不写入；确认且保存成功后显示「取消展示」。取消展示直接保存；失败保留上一次服务端确认的状态并提示重试。
- 可见性由服务端决定。明确关闭优先于官方标记；没有记录的普通策略默认不公开。广场列表和公开详情执行相同过滤。此次不改变暂停、停止或删除规则，不部署。

选用固定底栏的独立按钮，操作和状态一眼可见；保留信息区开关会有两个入口，藏进更多菜单则不符合直接操作的要求。
