# 未登录“我的”页与品牌视觉升级设计

## 背景与目标

BitPongo 当前未登录“我的”页只有一张问号人物插图、一个小尺寸登录按钮和语言按钮，无法表达产品价值，也缺少直接注册入口。前端字体同时混用了 Avenir、STIX、Verdana、Osaka、Apple SD Gothic Neo 和平台字体，造成中英文及数字显示不统一。移动端图标为橙底白色字母 `B`，图形层次、亲和力和识别度不足，启动页仍使用同一旧素材。

本次采用“暖橙亲和智能助手”方向，统一未登录页面、全局字体、App 图标和启动页视觉。修改范围仅限 `/Volumes/ExternalDrive/Code/github/bitpongo-front` 与 `/Volumes/ExternalDrive/Code/github/bitpongo-mobile`，不修改后端 API 和任何 `zhitoubao` 目录。

## 视觉方向

品牌主色继续使用暖橙，配合暖白背景、深色正文、圆润卡片和轻量阴影。整体强调可信、清晰和亲和，不采用复杂行情线、机器人面孔或高饱和霓虹效果。

核心视觉标识为圆润字母 `B` 与小型四角星光。`B` 保留 BitPongo 品牌识别，星光表达智能辅助。页面与图标共享相同的暖橙、白色和深色体系。

## 未登录“我的”页

### 页面结构

未登录状态改为完整的单列欢迎页：

1. 暖橙渐变欢迎卡片。
2. 圆润 `B` 星光标识。
3. 欢迎标题和“让自动化交易更简单”的简短说明。
4. 黑色主按钮“登录”。
5. 白底描边次按钮“注册”。
6. 三项核心能力卡片：自动化策略、安全连接交易所、实时运行提醒。
7. 底部语言设置列表项，继续打开现有语言弹层。

移除当前占据大量空间的蓝色问号人物插图。登录按钮继续跳转 `/login`，新增注册按钮跳转 `/register`，语言切换继续使用现有 `switchLang`。已登录页面的数据与导航行为不变。

### 响应式与可访问性

页面以 375px 移动视口为主要基准，同时适配更窄设备和 Web 浏览器。内容区使用安全边距和最大宽度；按钮具有足够触控高度；图标附带可读文本；正文与背景保持清晰对比。页面尺寸使用 `rem`，避免当前 750px 转换规则缩小字号。

### 国际化

为简体中文、繁体中文和英文增加欢迎标题、说明、注册按钮及三项能力文案。文案必须通过现有 Vue I18n 获取，不在模板中硬编码中文。

## 全局字体

在全局样式中定义 `--app-font-family`，使用平台原生无衬线字体栈：

```css
-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "PingFang TC", Roboto, "Noto Sans CJK SC", "Helvetica Neue", Arial, sans-serif
```

`html`、`body`、`#app`、按钮、输入框、选择框和文本域统一继承该变量。正文默认字重使用 `400`，标题和关键数据按页面需要使用 `600` 或 `700`，取消当前 `#app` 和 `body` 的全局 `500`。

清理业务源码中 STIX、Verdana、Osaka、Apple SD Gothic Neo、PingFang HK 等局部 `font-family` 覆盖，使所有普通文字继承全局字体。`src/assets/font/iconfont.css` 的图标字体声明保持不变，避免图标字形失效。

## App 图标与启动页

### 主图标

使用 `imagegen` 生成 1024×1024 品牌主图标：

- 全幅暖橙渐变背景，不预先绘制圆角，由系统应用图标蒙版。
- 中央为白色圆润几何 `B`。
- `B` 右上角加入一枚小型四角星光。
- 使用轻微层次与柔和高光，但在 48px 下仍保持轮廓清晰。
- 不包含文字、行情图、机器人脸、水印、投影到画布外或透明边缘。

新主图标先保存为版本化候选文件，检查通过后才替换 `assets/branding/app_icon.png`。随后使用 `flutter_launcher_icons` 重新生成 Android 和 iOS 的全部尺寸。

### Android 自适应图标

从同一视觉生成适合 Android 自适应图标安全区的前景素材，保持 `B` 与星光完整落在中央安全区域。背景使用与主图标一致的暖橙色，避免圆形、方形和水滴形蒙版裁切主体。更新 `pubspec.yaml` 的 `adaptive_icon_foreground` 引用并重新生成资源。

### 启动页

启动页沿用暖橙背景并使用同一 `B` 星光标识，替换旧 `assets/branding/splash.png` 后重新运行 `flutter_native_splash`。启动页不加入额外标语，避免小屏和启动过渡中产生排版问题。

## 测试与验收

采用测试先行：

- 未登录“我的”页组件测试验证欢迎区、登录、注册、三项能力和语言入口。
- 路由测试验证登录、注册与语言弹层交互不变。
- 样式测试验证关键字号使用 `rem`、按钮高度、卡片边界与全局字体变量。
- 字体扫描测试阻止业务源码重新引入被清理的局部字体族，同时排除图标字体文件。
- 图标源文件验证为 1024×1024、RGB/RGBA PNG；生成后的 Android/iOS 资源清单完整。
- 在 48px、Android 自适应蒙版和 iOS 图标预览中检查 `B` 与星光仍清晰、不被裁切。
- 运行前端目标测试、完整测试、类型检查与生产构建；运行 Flutter 静态分析、完整测试、图标生成命令和可用的原生平台构建。

## 验收标准

- 未登录“我的”页无需滚动过多即可看见品牌说明、登录和注册入口。
- 三项核心能力和语言入口清楚可读，三种语言文案完整。
- 普通业务文字在全站统一继承系统无衬线字体，图标字体正常。
- 新图标在桌面、启动器和系统设置的小尺寸场景中具有清晰辨识度。
- Android 自适应图标主体不被常见蒙版裁切；iOS 图标没有透明边缘或预绘圆角。
- 启动页与 App 图标使用同一品牌标识。
- 不改变登录、注册、已登录“我的”页、后端协议和账户数据流。
